# 具身意见动力学中注意力（u）与偏见（b）的设计原理（并道信心版）

本文档详细阐述在自动驾驶变道决策中，如何将物理感知（距离、速度）映射为意见动力学模型的两个核心参数：**外部偏见 `b`（客观机会）** 与**主观注意力 `u`（并道信心）**，以及这两个参数如何驱动意见 `x`（变道意愿）的实时更新。

---

## 1. 核心意见动力学公式（理论基础）

我们严格遵循第一篇论文（Bizyaeva et al., 2022）公式 (6) 的单智能体结构：

\[
\dot{x} = -d \cdot x + u(t) \cdot \tanh(\alpha \cdot x) + b(t)
\]

**⚠️ 关键结构警告**：
- **`b(t)` 必须加在 `tanh` 外部**，作为独立的客观拉力。
- **`u(t)` 乘以 `tanh` 外部**，作为主观增益。
- **物理含义**：`b` 决定“该往哪边去”（正负方向），`u` 决定“动作多快多猛”（执行力度）。

---

## 2. 外部偏见 `b(t)` 的设计（客观机会）

`b(t)` 只反映物理世界的**客观事实**：当前的空隙是否允许变道。它**只依赖于纵向距离和纵向速度变化**，不涉及主观情绪。

### 2.1 计算公式

\[
b(t) = \tanh\big( k_{gap} \cdot (gap(t) - d_{safe}) + k_{vel} \cdot \dot{gap}(t) \big)
\]

### 2.2 参数详细解释

| 参数 | 符号 | 单位 | 典型值 | 物理含义 |
| :--- | :--- | :--- | :--- | :--- |
| **当前空隙** | `gap` | m | 0.5 ~ 5.0 | 前车（1号）与后车（2号）之间的实际纵向距离。 |
| **安全阈值** | `d_safe` | m | 1.0 | 驾驶员认为“安全”的最小空隙。小于此值，`b` 开始变负。 |
| **距离灵敏度** | `k_gap` | 1/m | 2.0 | 空隙偏离安全值时的反应强度。越大越“斤斤计较”。 |
| **速度变化率** | `gap_dot` | m/s | -2 ~ 2 | 空隙的缩张速度。正=后车让路/前车加速；负=后车逼近。 |
| **速度灵敏度** | `k_vel` | s/m | 0.8 | 对空隙变化趋势的敏感度。越大越“未雨绸缪”。 |
| **输出范围** | `b` | — | (-1, 1) | 通过 `tanh` 压到 [-1,1]。正=支持变道，负=反对变道。 |

---

## 3. 主观注意力 `u(t)` 的设计（并道执行信心）**【本次核心更新】**

在变道场景中，`u` 不再代表“碰撞恐惧度”，而是代表 **“此刻执行并道动作的把握有多大”**。

- **位置接近**（本车已经贴到了目标空隙旁边） → 机会触手可及 → **`u` 增大**。
- **速度一致**（本车与目标空隙中的前后车速度相同） → 不会撞前车，也不会被后车撞 → **`u` 增大**。
- **如果离得还远（位置不接近）或者速度差很大** → 硬变道很危险 → **`u` 减小**（再等等）。

### 3.1 数学表达（二维高斯函数 / RBF）

我们不再单独评估“前车”和“后车”，而是直接评估 **“目标空隙（Gap）”** 的整体状态：

- **目标空隙中心位置**：\( x_{gap} = \frac{x_{front} + x_{rear}}{2} \)
- **目标空隙平均速度**：\( v_{gap} = \frac{v_{front} + v_{rear}}{2} \)
- **本车到空隙中心的纵向距离**：\( d_{gap} = x_{gap} - x_{ego} \)（正=空隙在前方）
- **本车与空隙的速度差**：\( dv_{gap} = v_{ego} - v_{gap} \)（正=本车比空隙平均速度快）

**注意力 `u` 的计算公式**：

\[
u = u_{base} + u_{amp} \cdot \exp\left( -\frac{d_{gap}^2}{2\sigma_d^2} - \frac{dv_{gap}^2}{2\sigma_v^2} \right)
\]

### 3.2 参数详细解释

| 参数 | 符号 | 单位 | 典型值 | 物理含义 |
| :--- | :--- | :--- | :--- | :--- |
| **本车到空隙中心的距离** | `d_gap` | m | 实时 | 本车车头与前后车中间点的纵向距离。0 表示正好对齐。 |
| **本车与空隙的速度差** | `dv_gap` | m/s | 实时 | 本车速度与前后车平均速度的差。0 表示完全同步。 |
| **基础注意力** | `u_base` | — | 0.2 | 即使时机不完美，也保留的最低执行意愿（不至于完全睡着）。 |
| **峰值幅度** | `u_amp` | — | 2.5 | 当位置和速度都完美时，注意力能达到的最高额外增量。 |
| **位置容忍度** | `σ_d` | m | 2.0 | 本车可以偏离空隙中心多少米，注意力才明显下降。越大越“宽容”。 |
| **速度容忍度** | `σ_v` | m/s | 1.5 | 本车与空隙速度差多少 m/s，注意力才明显下降。越大越“宽容”。 |

### 3.3 物理直觉解析（关键场景对比）

| 驾驶场景 | `d_gap` | `dv_gap` | 计算出的 `u` | 对应驾驶行为 |
| :--- | :--- | :--- | :--- | :--- |
| **堵车蠕行（完美时机）** | ≈ 0 m（已在空隙中间） | ≈ 0 m/s（速度一致） | `u_base + u_amp`（峰值） | **果断并道**：位置对了，速度也匹配，此时不变道更待何时。 |
| **正在靠近空隙** | 30 m（还在远处） | 5 m/s（过快） | 接近 `u_base`（极小） | **保持等待**：离目标空隙还远，还没到做决定的时机。 |
| **已对齐，但后车很快** | ≈ 0 m（对齐了） | -3 m/s（本车比空隙慢很多） | 中等偏小（高斯衰减） | **犹豫/放弃**：虽然纵向对齐了，但速度差太大（后车在逼近），此时硬并道危险，信心不足。 |
| **隔壁车道有车** | **只看纵向 `x`** | **只看速度 `vx`** | 完全不受横向 `y` 影响 | **专注于目标**：并道只看纵向空隙是否对齐，隔壁车道的横向位置不影响“时机判断”。 |

## 4. 如何用 `u` 和 `b` 生成意见 `x`（实时更新流程）

### 4.1 连续时间微分方程

\[
\dot{x} = -d \cdot x + u \cdot \tanh(\alpha \cdot x) + b
\]

### 4.2 离散时间更新（欧拉积分，实际部署）

现实中，我们以固定频率（如 50Hz，`dt=0.02s`）循环执行：

```
每过 dt 秒：
  1. 传感器读取：前车、后车的 (x, vx)，计算 gap 和 gap_dot。
  
  2. 计算客观偏见 b：
     b = tanh(k_gap*(gap - d_safe) + k_vel*gap_dot)
  
  3. 计算并道信心 u：
     x_gap = (x_front + x_rear) / 2        # 空隙中心
     v_gap = (vx_front + vx_rear) / 2      # 空隙平均速度
     d_gap = x_gap - x_ego                 # 纵向距离偏差
     dv_gap = vx_ego - v_gap               # 速度差
     confidence = exp( -d_gap²/(2σ_d²) - dv_gap²/(2σ_v²) )
     u = u_base + u_amp * confidence
  
  4. 计算意见变化率：
     x_dot = -d * x + u * tanh(alpha * x) + b
  
  5. 更新意见：
     x = x + x_dot * dt
  
  6. 输出 x 给控制器（决定方向盘目标横向偏移）
```

## 5. 参数调优快速指南（针对并道场景）

| 想要的行为 | 调节参数 | 调节方向 |
| :--- | :--- | :--- |
| **更果断（爱变道）** | `u_amp` | 调大（如 4.0），一旦时机完美，意见瞬间冲顶。 |
| **更犹豫（不爱变道）** | `u_amp` | 调小（如 1.0），即使时机完美，增长也平缓。 |
| **提前准备变道（开阔高速）** | `σ_d` | 调大（如 5.0），距离空隙中心还较远时就已经信心很高。 |
| **必须贴到目标才变道（拥挤城市）** | `σ_d` | 调小（如 1.0），必须几乎贴到空隙正中间才敢行动。 |
| **允许速度有误差（激进）** | `σ_v` | 调大（如 3.0），速度差较大时也敢并道。 |
| **必须速度完美匹配（保守）** | `σ_v` | 调小（如 0.5），速度差超过 0.5m/s 就不敢动。 |
| **防止意见抖动** | `d_inertia` | 调大（如 0.4），增加意见的惯性/滞后性。 |

---


## 6. 总结

- **`b`（偏见）**：由**纵向距离与速度变化**驱动，决定“客观允不允许变道”（正负号）。
- **`u`（注意力）**：由**本车与目标空隙中心的纵向距离和速度差**驱动，采用**二维高斯函数**评估并道时机成熟度，决定“执行信心有多强”（幅值）。
- **`x`（意见）**：通过 `-d*x + u*tanh(αx) + b` 实时积分生成，兼具**惯性记忆**、**时机调制（信心）**和**客观拉力**，最终驱动物理控制器。

这一设计完美贴合了人类驾驶员的直觉：**“位置对上、速度同步，我就果断并；对不上、不同步，我就老实等着。”** 😊
